## Задание

Вам дана заготовка Django-приложения для управления курсами и студентами. Вся бизнес-логика уже реализована, но совершенно нет тестов.

### Модели

**Student (Студент):**
- `name` — имя (TextField)
- `birth_date` — дата рождения (DateField, может быть null)

**Course (Курс):**
- `name` — название (TextField)
- `students` — студенты на курсе (ManyToManyField)

### API Эндпоинты

Базовый URL: `/api/v1/`

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/courses/` | Получить список всех курсов |
| POST | `/courses/` | Создать новый курс |
| GET | `/courses/{id}/` | Получить детали курса |
| PUT | `/courses/{id}/` | Обновить курс |
| DELETE | `/courses/{id}/` | Удалить курс |

**Фильтрация:**
- По `id` (можно передать несколько): `?id=1&id=2`
- По `name`: `?name=Python`

## Что нужно сделать

### Часть 1: Настройка тестового окружения

1. Создайте структуру тестов в папке `tests/`:
```
tests/
├── __init__.py
├── conftest.py              # ← Фикстуры
├── students/
│   ├── __init__.py
│   └── test_courses_api.py  # ← Тесты для API
```

2. В файле `tests/conftest.py` создайте фикстуры:
   - `api_client` — клиент для API (APIClient)
   - `course_factory` — фабрика для создания курсов (model_bakery)
   - `student_factory` — фабрика для создания студентов (model_bakery)

### Часть 2: Написание тестов для API

Напишите тесты для следующих сценариев. **Все тесты должны проверять код ответа (status_code).**

#### 2.1. Получение списка курсов (GET /courses/)

**Тест-кейс:** Проверка получения списка курсов

1. Создайте несколько курсов через фабрику (например, 5 штук)
2. Выполните GET-запрос к `/api/v1/courses/`
3. Проверьте:
   - Код ответа: 200
   - Количество курсов в ответе соответствует созданному
   - Данные курсов корректны

#### 2.2. Получение деталей курса (GET /courses/{id}/)

**Тест-кейс:** Проверка получения одного курса

1. Создайте курс через фабрику
2. Выполните GET-запрос к `/api/v1/courses/{id}/`
3. Проверьте:
   - Код ответа: 200
   - Данные курса соответствуют созданному

**Тест-кейс:** Проверка получения несуществующего курса

1. Выполните GET-запрос к `/api/v1/courses/999/`
2. Проверьте: код ответа 404

#### 2.3. Фильтрация курсов

**Тест-кейс:** Фильтрация по id

1. Создайте несколько курсов через фабрику
2. Выполните GET-запрос с параметром: `?id={id_одного_курса}`
3. Проверьте:
   - Код ответа: 200
   - В ответе только один курс с указанным id

**Тест-кейс:** Фильтрация по name

1. Создайте курсы с разными названиями (например, "Python", "Java", "Python Advanced")
2. Выполните GET-запрос с параметром: `?name=Python`
3. Проверьте:
   - Код ответа: 200
   - В ответе только курсы с названием, содержащим "Python"

#### 2.4. Создание курса (POST /courses/)

**Тест-кейс:** Успешное создание курса

1. Подготовьте JSON-данные для нового курса:
   ```json
   {"name": "Новый курс", "students": []}
   ```
2. Выполните POST-запрос к `/api/v1/courses/`
3. Проверьте:
   - Код ответа: 201 (Created)
   - Курс создался в базе данных
   - Данные курса соответствуют отправленным

**Тест-кейс:** Создание курса с некорректными данными

1. Подготовьте JSON-данные без поля `name`
2. Выполните POST-запрос
3. Проверьте: код ответа 400 (Bad Request)

#### 2.5. Обновление курса (PUT /courses/{id}/)

**Тест-кейс:** Успешное обновление курса

1. Создайте курс через фабрику
2. Подготовьте JSON-данные для обновления: `{"name": "Обновлённое название"}`
3. Выполните PUT-запрос к `/api/v1/courses/{id}/`
4. Проверьте:
   - Код ответа: 200
   - Название курса в базе данных обновилось

#### 2.6. Удаление курса (DELETE /courses/{id}/)

**Тест-кейс:** Успешное удаление курса

1. Создайте курс через фабрику
2. Выполните DELETE-запрос к `/api/v1/courses/{id}/`
3. Проверьте:
   - Код ответа: 204 (No Content)
   - Курс удалён из базы данных

**Тест-кейс:** Удаление несуществующего курса

1. Выполните DELETE-запрос к `/api/v1/courses/999/`
2. Проверьте: код ответа 404

### Шаг 3. Создайте файл conftest.py с фикстурами

```python
import pytest
from rest_framework.test import APIClient
from model_bakery import baker


@pytest.fixture
def api_client():
    """Фикстура для клиента API"""
    return APIClient()


@pytest.fixture
def course_factory():
    """Фикстура для создания курсов"""
    def factory(**kwargs):
        return baker.make('students.Course', **kwargs)
    return factory


@pytest.fixture
def student_factory():
    """Фикстура для создания студентов"""
    def factory(**kwargs):
        return baker.make('students.Student', **kwargs)
    return factory
```
