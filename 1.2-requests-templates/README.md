# Домашнее задание «Обработка запросов и шаблоны» 

## О задании

В этом практическом задании вы закрепите навыки работы с HTTP-запросами, функциями представлений, шаблонами Django и постраничным выводом данных.

### Образовательные результаты

После выполнения работы вы сможете:

- создавать view-функции;
- получать параметры HTTP-запроса;
- передавать данные в шаблоны через `render()`;
- использовать шаблоны Django для формирования HTML;
- реализовывать пагинацию стандартными средствами Django.

**Время на выполнение** — 90 минут.

Это задание для самостоятельной работы — оно не будет проверяться экспертом. После загрузки вашего решения вы получите **эталонное решение от эксперта**. 

### Чек-лист подготовки к выполнению задания:
Перед выполнением задания изучите видеолекцию «Обработка запросов и шаблоны».
