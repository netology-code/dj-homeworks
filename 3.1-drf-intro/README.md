# Знакомство с API на примере Django REST framework

В этом задании вы познакомитесь с компонентами Django REST Framework (DRF) и реализуете простой REST API для «умного дома»: научитесь строить эндпоинты, превращать модели в JSON с помощью сериализаторов и отдавать данные по GET-запросам. Это позволит вам уверенно работать с современным подходом к разработке backend-приложений и подготовит к следующим темам курса (CRUD, права доступа, тестирование).

## Цели задания

- научиться создавать эндпоинты API с использованием Django REST Framework;
- научиться настраивать сериализаторы для моделей (`ModelSerializer`) и вложенные сериализаторы;
- научиться обрабатывать GET-запросы и возвращать данные в формате JSON;
- научиться проверять работу API через браузер и Postman.

**Время на выполнение** — 90 минут.

## Задание

1. [Умный дом](./smart_home) — реализуйте REST API для датчиков температуры.

Работа должна соответствовать принятому [стилю оформления кода](https://github.com/netology-code/codestyle/tree/master/python).

Полное описание структуры репозитория, инструкции по открытию проекта в IDE и его запуску — в [info.md](./info.md).

## Инструкция к выполнению 

1. Откройте папку `smart_home` в редакторе (как это сделать — в [info.md](./info.md)).
2. Установите зависимости: `pip install -r requirements.txt`.
3. Опишите модели датчика и измерения в `measurement/models.py`.
4. Настройте сериализаторы в `measurement/serializers.py`.
5. Реализуйте представления в `measurement/views.py` и маршруты в `measurement/urls.py`.
6. Загрузите тестовые данные: `python manage.py migrate && python manage.py loaddata sample_data`.
7. Запустите сервер `python manage.py runserver` и проверьте эндпоинты через браузер и Postman.
