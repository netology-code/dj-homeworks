# Описание репозитория «Первый проект на Django»

## Структура репозитория

```
.
├── first_project/                 # Папка с Django-проектом
│   ├── first_project/             # Папка с настройками проекта
│   │   ├── __init__.py            # Указывает Python, что это пакет
│   │   ├── settings.py            # Настройки Django-проекта (БД, приложения, время)
│   │   ├── urls.py                # Карта маршрутов (URL -> View) — ЗДЕСЬ НУЖНО ПРАВИТЬ
│   │   └── wsgi.py                # Точка входа для веб-сервера (не трогаем)
│   ├── app/                       # Приложение
│   │   ├── migrations/            # Папка с миграциями базы данных
│   │   │   └── __init__.py
│   │   ├── __init__.py
│   │   ├── admin.py               # Настройки для встроенной админки
│   │   ├── apps.py                # Конфигурация приложения
│   │   ├── models.py              # Модели данных (сейчас пусто)
│   │   ├── tests.py               # Тесты
│   │   └── views.py               # View-функции — ЗДЕСЬ НУЖНО ПРАВИТЬ
│   ├── manage.py                  # Основной скрипт для управления проектом
│   ├── requirements.txt           # Список зависимостей
│   └── README.md                  # Описание задания
├── README.md                      # Главный README репозитория
├── HOW_TO_WORK.md                 # Инструкция по работе с репозиторием
└── info.md                        # Этот файл — описание структуры
```

## Что за что отвечает

| Файл | Назначение | Что нужно сделать |
|------|------------|-------------------|
| `first_project/first_project/urls.py` | Маршрутизация URL-адресов | Добавить три пути к view-функциям |
| `first_project/app/views.py` | Бизнес-логика приложения | Реализовать три view-функции |
| `first_project/first_project/settings.py` | Настройки проекта | Убедиться, что приложение `app` подключено |
| `first_project/manage.py` | Управление проектом | Использовать для запуска сервера |

## Как открыть проект в среде разработки

### Вариант 1: PyCharm (рекомендуется)

1. Запустите PyCharm.
2. Нажмите **File -> Open** и выберите папку `first_project`.
3. PyCharm автоматически определит Django-проект и предложит настроить виртуальное окружение.
4. Согласитесь на создание виртуального окружения (venv).
5. Откройте терминал внутри PyCharm и выполните:
   ```bash
   pip install -r requirements.txt
   ```

### Вариант 2: VS Code

1. Запустите VS Code.
2. Нажмите **File -> Open Folder** и выберите папку `first_project`.
3. Убедитесь, что установлено расширение **Python** от Microsoft.
4. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```
5. Активируйте виртуальное окружение:
   - **Windows:** `venv\Scripts\activate`
   - **Mac/Linux:** `source venv/bin/activate`
6. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### Вариант 3: Командная строка / Терминал

1. Откройте терминал и перейдите в папку `first_project`.
2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```
3. Активируйте виртуальное окружение (см. выше).
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Как запустить проект

После того как вы открыли проект и установили зависимости:

```bash
python manage.py runserver
```

После запуска откройте в браузере: `http://127.0.0.1:8000/`

## Как проверить результат

1. Откройте главную страницу — вы должны увидеть список ссылок.
2. Перейдите по ссылке «Конвертировать валюту».
3. Добавьте параметры в URL: `?from=USD&to=RUB&amount=10`
4. Проверьте, что результат конвертации отображается корректно.
5. Проверьте страницу «О проекте».

## Что делать, если что-то пошло не так

1. Проверьте, что вы установили все зависимости: `pip install -r requirements.txt`
2. Проверьте, что вы находитесь в правильной директории (там, где `manage.py`).
3. Внимательно прочитайте сообщение об ошибке в терминале или в браузере.
4. Проверьте синтаксис вашего кода в `urls.py` и `views.py`.
5. Убедитесь, что вы импортировали все функции в `urls.py`.
6. Проверьте, что приложение `app` добавлено в `INSTALLED_APPS` в `settings.py`.
