# Первый проект на Django: Конвертер валют

## Задание

Вам дана заготовка Django-проекта. В проект уже добавлено одно приложение — `app`.

Ваша задача — доработать заготовку и реализовать простое веб-приложение для конвертации валют.

### Страницы, которые вы должны создать:

#### 1. Главная страница (`/`)

- **URL:** `/` (корень сайта)
- **View-функция:** `home_view` (уже частично написана в `app/views.py`)
- **Задача:** Сгенерировать HTML-страницу со списком ссылок на две другие страницы. Ссылки должны строиться с помощью функции `reverse()`.

**Пример того, как должно выглядеть в браузере:**
```
Добро пожаловать в конвертер валют!

Страницы:
- Конвертировать валюту
- О проекте
```

#### 2. Страница конвертации (`/convert/`)

- **URL:** `convert/`
- **View-функция:** `convert_view` (написать самостоятельно)
- **Задача:** Принимать GET-параметры из запроса, выполнять конвертацию и возвращать результат.

**Параметры запроса (GET):**

| Параметр | Описание | Пример |
|----------|----------|--------|
| `from` | Код исходной валюты | `USD` |
| `to` | Код целевой валюты | `RUB` |
| `amount` | Сумма для конвертации | `100` |

**Пример корректного URL для проверки:**
```
http://127.0.0.1:8000/convert/?from=USD&to=RUB&amount=10
```

**Логика работы:**
1. Получить параметры `from`, `to`, `amount` из `request.GET`.
2. Проверить, что все три параметра переданы и имеют корректные значения.
3. Использовать фиксированный словарь с курсами валют, заданный в `views.py`:
   ```python
   EXCHANGE_RATES = {
       'USD_RUB': 90.5,
       'EUR_RUB': 98.0,
       'USD_EUR': 0.92,
       'EUR_USD': 1.09,
       'RUB_USD': 0.011,
       'RUB_EUR': 0.010,
   }
   ```
4. Если курс для указанной пары существует, вернуть результат:
   ```
   100 USD = 9050 RUB
   ```
5. Если курс не найден, вернуть сообщение об ошибке:
   ```
   Курс для пары USD → RUB не найден
   ```
6. Если параметры не переданы или переданы не все, вернуть сообщение с инструкцией:
   ```
   Пожалуйста, укажите параметры: from, to, amount
   ```

#### 3. Страница «О проекте» (`/about/`)

- **URL:** `about/`
- **View-функция:** `about_view` (написать самостоятельно)
- **Задача:** Вернуть HTML-страницу с описанием проекта и инструкцией по использованию.

**Пример содержания страницы:**
```
О проекте

Это простое веб-приложение для конвертации валют.

Как пользоваться:
1. Перейдите на страницу /convert/
2. Добавьте параметры в URL:
   ?from=USD&to=RUB&amount=100

Доступные валюты: USD, EUR, RUB.
```

## Инструкция по выполнению

### Шаг 1. Откройте проект в IDE

1. Запустите вашу среду разработки (PyCharm, VS Code или другую).
2. Откройте папку `first_project`.

### Шаг 2. Изучите структуру проекта

```
first_project/
├── first_project/
│   ├── __init__.py
│   ├── settings.py      # Настройки проекта
│   ├── urls.py          # ГЛАВНЫЙ ФАЙЛ — настройка маршрутов
│   └── wsgi.py
├── app/
│   ├── migrations/
│   ├── __init__.py
│   ├── admin.py
│   ├── apps.py
│   ├── models.py
│   ├── tests.py
│   └── views.py         # ГЛАВНЫЙ ФАЙЛ — view-функции
├── manage.py
└── requirements.txt
```

Убедитесь, что приложение `app` добавлено в `INSTALLED_APPS` в файле `first_project/settings.py`.

### Шаг 3. Настройте маршруты (файл `urls.py`)

В файле `first_project/urls.py`:
1. Импортируйте все необходимые view-функции из `app.views`.
2. Добавьте три маршрута в список `urlpatterns`.

### Шаг 4. Реализуйте view-функции (файл `views.py`)

В файле `app/views.py`:

1. **Доработайте `home_view`** — замените пустые строки в словаре `pages` на вызовы `reverse()` с правильными именами маршрутов.

2. **Напишите `convert_view`** — реализуйте логику конвертации валют.

3. **Напишите `about_view`** — создайте HTML-страницу с описанием проекта.

### Шаг 5. Запустите и проверьте

```bash
python manage.py runserver
```

Откройте в браузере и проверьте все страницы.

## Подсказки

- Для получения параметров из GET-запроса используйте `request.GET.get('имя_параметра')`.
- Для конвертации валют используйте словарь `EXCHANGE_RATES`.
- Для построения ссылок на главной странице используйте `reverse()`.
- Если что-то пошло не так, обратите внимание на жёлтую страницу ошибки Django — в ней подробно описана проблема.
