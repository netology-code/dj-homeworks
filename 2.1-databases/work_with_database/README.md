# Каталог товаров: загрузка данных из CSV

## Задание

Вы работаете в компании, которая продаёт телефоны. Ваш партнёр предоставил файл с данными о телефонах в формате CSV. Вам необходимо:

1. Создать модель `Phone` для хранения данных о телефонах.
2. Написать скрипт для загрузки данных из CSV-файла в базу данных.
3. Реализовать страницу каталога с возможностью сортировки.
4. Реализовать страницу отдельного телефона.

### Что нужно сделать

#### 1. Модель `Phone` (файл `models.py`)

Создайте модель `Phone` со следующими полями:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `IntegerField` | Основной ключ (первичный ключ модели) |
| `name` | `CharField` | Название телефона |
| `price` | `DecimalField` или `IntegerField` | Цена |
| `image` | `URLField` | Ссылка на изображение |
| `release_date` | `DateField` | Дата выхода |
| `lte_exists` | `BooleanField` | Наличие поддержки LTE |
| `slug` | `SlugField` | Уникальный идентификатор для URL (на основе name) |

**Важно:** Поле `slug` должно автоматически создаваться из поля `name` при сохранении объекта. Используйте `pre_save` сигнал или переопределите метод `save()`.

#### 2. Скрипт загрузки данных (файл `management/commands/import_phones.py`)

Напишите Django-команду для импорта данных из файла `phones.csv`. Команда должна:

- Читать файл `phones.csv` (разделитель — точка с запятой `;`).
- Для каждой строки создавать объект модели `Phone`.
- Генерировать `slug` из поля `name`.
- Сохранять объект в базу данных.

**Запуск команды:**
```bash
python manage.py import_phones
```

#### 3. Страница каталога (функция `show_catalog`)

Реализуйте страницу каталога по адресу `/catalog/`.

**Функциональность:**
- Отображение всех телефонов.
- Сортировка через GET-параметр `sort`:
  - `?sort=name` — по названию (алфавитный порядок)
  - `?sort=min_price` — по цене (от дешёвых к дорогим)
  - `?sort=max_price` — по цене (от дорогих к дешёвым)

**Примеры URL:**
- `/catalog/` — все телефоны (без сортировки)
- `/catalog/?sort=name` — сортировка по названию
- `/catalog/?sort=min_price` — сначала дешёвые

#### 4. Страница телефона (функция `show_product`)

Реализуйте страницу отдельного телефона по адресу `/catalog/<slug>/`.

**Пример URL:**
- `/catalog/iphone-x/` — страница телефона с slug = "iphone-x"

**Что должно отображаться:**
- Название
- Цена
- Изображение
- Дата выпуска
- Наличие LTE (да/нет)

## Подсказки

### Для работы с CSV

Используйте стандартную библиотеку `csv`:

```python
import csv

with open('phones.csv', 'r') as file:
    phones = list(csv.DictReader(file, delimiter=';'))
```

### Для генерации slug

Используйте функцию `slugify`:

```python
from django.utils.text import slugify

slug = slugify(phone_name)
```

### Для сортировки

Получите параметр из `request.GET`:

```python
sort_param = request.GET.get('sort')

if sort_param == 'name':
    phones = Phone.objects.all().order_by('name')
elif sort_param == 'min_price':
    phones = Phone.objects.all().order_by('price')
elif sort_param == 'max_price':
    phones = Phone.objects.all().order_by('-price')
else:
    phones = Phone.objects.all()
```

### Для фильтрации по slug

```python
phone = Phone.objects.get(slug=slug)
```
