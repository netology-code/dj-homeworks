# Работа с ORM

В этом блоке вы научитесь работать с базами данных в Django через ORM (Object-Relational Mapping). Вы освоите создание моделей, настройку связей между ними, фильтрацию данных и оптимизацию запросов.

Необходимо выполнить и предоставить на проверку следующие задачи:

1. [Обязательное задание: Каталог товаров](./work_with_database) — загрузка данных из CSV-файла и отображение каталога.
2. [Дополнительное задание: Онлайн-библиотека](./models_list_displaying) — работа с датами и пагинацией.

**Важно:** Присылать на проверку нужно сразу все обязательные задачи. Дополнительные задачи не влияют на получение зачёта, но помогут лучше закрепить материал.

Работы должны соответствовать принятому [стилю оформления кода](https://github.com/netology-code/codestyle/tree/master/python).

Любые вопросы по решению задач задавайте в чате учебной группы.
