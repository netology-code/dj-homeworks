```
│   │   ├── migrations/            # Папка с миграциями базы данных
│   │   │   └── __init__.py
│   │   ├── __init__.py
│   │   ├── admin.py               # Настройки для встроенной админки
│   │   ├── apps.py                # Конфигурация приложения
│   │   ├── models.py              # Модели данных (сейчас пусто)
│   │   ├── serializers.py         # Сериализаторы и валидаторы — ЗДЕСЬ НУЖНО ПРАВИТЬ
│   │   ├── tests.py               # Тесты
│   │   ├── urls.py                # Cвязывает веб-адреса (URL) с функциями или классами (views)
│   │   └── views.py               # View-функции — ЗДЕСЬ НУЖНО ПРАВИТЬ
│   ├── manage.py                  # Основной скрипт для управления проектом
│   ├── README.md                  # Описание задания
│   ├── requests-examples.http     # Пример http-запросов для проверки работоспособности
│   ├── requirements.txt           # Список зависимостей
│   └── info.md                    # Вы здесь)

├── HOW_TO_WORK.md                 # Инструкция по работе с репозиторием
└── info.md                        # Этот файл — описание структуры
```

## Как открыть проект в среде разработки

### Вариант 1: PyCharm (рекомендуется)

1. Запустите PyCharm.
2. Нажмите **File -> Open** и выберите папку `first_project`.
3. PyCharm автоматически определит Django-проект и предложит настроить виртуальное окружение.
4. Согласитесь на создание виртуального окружения (venv).
5. Откройте терминал внутри PyCharm и выполните:
   ```bash
   pip install -r requirements.txt
   ```

### Вариант 2: VS Code

1. Запустите VS Code.
2. Нажмите **File -> Open Folder** и выберите папку `first_project`.
3. Убедитесь, что установлено расширение **Python** от Microsoft.
4. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```
5. Активируйте виртуальное окружение:
   - **Windows:** `venv\Scripts\activate`
   - **Mac/Linux:** `source venv/bin/activate`
6. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

### Вариант 3: Командная строка / Терминал

1. Откройте терминал и перейдите в папку `first_project`.
2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```
3. Активируйте виртуальное окружение (см. выше).
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Как запустить проект

После того как вы открыли проект и установили зависимости:

```bash
python manage.py runserver
```

После запуска откройте в браузере: `http://127.0.0.1:8000/`

## Как проверить результат

1. Запустите сервер командой `python manage.py runserver`.
2. Отправьте `POST`-запрос на `/api/v1/products/` и создайте несколько товаров.
3. Проверьте получение, изменение и удаление товаров через `GET`, `PATCH` и `DELETE`.
4. Выполните поиск товара: `/api/v1/products/?search=помид`.
5. Создайте склад через `POST /api/v1/stocks/`, передав адрес и список `positions`.
6. Получите склад по ID и проверьте, что в ответе присутствуют товары, их количество и цена.
7. Измените только адрес склада с помощью `PATCH` — существующие позиции не должны исчезнуть.
8. Проверьте фильтрацию складов по товару: `/api/v1/stocks/?products=1`.
9. Если выполнено дополнительное задание, проверьте поиск складов: `/api/v1/stocks/?search=помид`.
10. Создайте достаточно записей и убедитесь, что списки товаров и складов разбиваются на страницы.


## Что делать, если что-то пошло не так

1. Проверьте, что вы установили все зависимости: `pip install -r requirements.txt`
2. Проверьте, что вы находитесь в правильной директории (там, где `manage.py`).
3. Внимательно прочитайте сообщение об ошибке в терминале или в браузере.
4. Проверьте синтаксис вашего кода в `serializers.py` и `views.py`.
